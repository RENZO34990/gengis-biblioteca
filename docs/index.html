¿Qué es este espacio?

Cada cuaderno es una página HTML autocontenida, construida a partir de fuentes académicas y periodísticas verificadas, curadas también en nuestra biblioteca de NotebookLM. No reemplaza el trabajo de investigación del club — le da un formato interactivo y permanente.

¿Cómo se conecta con Gengis?

Esta biblioteca es hermana del Observatorio de datos Gengis (comercio, monitor de 3 dimensiones, perfiles país). Las fuentes curadas aquí alimentan también al asistente de investigación reactivo del club.
